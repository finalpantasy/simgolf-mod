# Windows application icon

The maintainer selected the transparent logo supplied in issue #106:
https://github.com/finalpantasy/simgolf-mod/issues/106

Source attachment:
https://github.com/user-attachments/assets/1155acbc-98ab-41d7-a593-daa9440760bc

The ICO contains 16, 24, 32, 48, 64, 128 and 256 pixel RGBA versions of that
image. Resource 101 is embedded in the game, installer worker and updater.
No image data from the original game executable is used.
